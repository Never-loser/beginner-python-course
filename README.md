# Beginner Python Course

A fourteen-chapter introduction to Python, from installing it to writing
a finished project. Fifty lessons: two written pages to get set up, and
forty-eight Jupyter notebooks you can run and edit as you read.

```bash
pip install notebook
jupyter notebook          # then open any chapter folder
```

Chapter 1 is written in both English and Persian; the rest are in English.
