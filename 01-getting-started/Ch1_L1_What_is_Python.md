## 🇬🇧 English

### 1. Introduction
Python is a high-level, general-purpose programming language created by Guido van Rossum and first released in 1991. It emphasizes code readability, using clean, simple syntax that reads almost like plain English. This is one of the reasons Python is one of the best first programming languages for beginners.

### 2. Why Python?
- **Readable and simple syntax** — code looks almost like pseudocode.
- **General-purpose** — used in web development, data science, artificial intelligence, automation, game development, and more.
- **Huge ecosystem** — thousands of ready-made libraries (NumPy, Pandas, Django, TensorFlow, ...) so you rarely start from zero.
- **Large community** — millions of developers worldwide, meaning fast answers to almost any question.
- **Interpreted language** — code runs line by line, with no separate compiling step, which is great for learning and experimenting.

### 3. Where Is Python Used Today?
| Field | Examples |
|---|---|
| Web Development | Django, Flask (backend of many websites) |
| Data Science & Analytics | Pandas, NumPy |
| AI & Machine Learning | TensorFlow, PyTorch |
| Automation & Scripting | file renaming, email automation, web scraping |
| Game Development | Pygame |
| Scientific Computing | SciPy |

### 4. How This Course Works
Throughout this course we use **VS Code** together with the **Jupyter extension** to write and run Python code interactively. We move chapter by chapter — from basic syntax to small real projects, including some graphics work (Turtle, Matplotlib) along the way.

## 🇮🇷 فارسی

### ۱. مقدمه
پایتون یک زبان برنامه‌نویسی سطح‌بالا و همه‌منظوره است که توسط گیدو ون روسوم ساخته شد و اولین‌بار در سال ۱۹۹۱ منتشر شد. این زبان بر خوانایی کد تأکید دارد و از نحوی (syntax) ساده و تمیز استفاده می‌کند که تقریباً شبیه زبان انگلیسی روان است. همین موضوع باعث شده پایتون یکی از بهترین زبان‌ها برای شروع یادگیری برنامه‌نویسی باشد.

### ۲. چرا پایتون؟
- **نحو ساده و خوانا** — کد پایتون تقریباً شبیه شبه‌کد (pseudocode) است.
- **همه‌منظوره بودن** — در توسعه وب، علم داده، هوش مصنوعی، اتوماسیون، ساخت بازی و... استفاده می‌شود.
- **اکوسیستم بزرگ** — هزاران کتابخانه آماده (مثل NumPy، Pandas، Django، TensorFlow) که به‌ندرت پیش می‌آید از صفر شروع کنید.
- **جامعه بزرگ** — میلیون‌ها برنامه‌نویس در دنیا، یعنی پاسخ سریع برای تقریباً هر سؤالی.
- **زبان تفسیری (Interpreted)** — کد خط‌به‌خط اجرا می‌شود، بدون نیاز به کامپایل جداگانه؛ همین ویژگی برای یادگیری و آزمایش‌کردن عالی است.

### ۳. پایتون امروز کجا استفاده می‌شود؟
| حوزه | نمونه‌ها |
|---|---|
| توسعه وب | Django، Flask |
| علم داده و تحلیل داده | Pandas، NumPy |
| هوش مصنوعی و یادگیری ماشین | TensorFlow، PyTorch |
| اتوماسیون و اسکریپت‌نویسی | تغییر نام فایل‌ها، اتوماسیون ایمیل، استخراج داده از وب |
| ساخت بازی | Pygame |
| محاسبات علمی | SciPy |

### ۴. این دوره چطور پیش می‌رود؟
در طول این دوره از **VS Code** به‌همراه **افزونه Jupyter** برای نوشتن و اجرای تعاملی کد پایتون استفاده می‌کنیم. فصل‌به‌فصل پیش می‌رویم — از نحو پایه تا چند پروژه واقعی کوچک، همراه با کمی کار گرافیکی (Turtle، Matplotlib) در مسیر دوره.

### تمرین‌ها

**🟢 آسان**
به **سه اپلیکیشن یا وب‌سایتی که خودتان هرروز استفاده می‌کنید** فکر کنید (مثلاً اینستاگرام، یک اپ سفارش غذا، اپ بانکتان). برای هرکدام **یک جمله** بنویسید که حدس بزنید پایتون ممکن است پشت‌صحنه‌ی آن کجا استفاده شده باشد (فرانت‌اند، بک‌اند، سیستم پیشنهاددهنده، اتوماسیون و...).
> باید بر اساس اپ‌هایی باشد که **خودتان واقعاً استفاده می‌کنید** — اسم آن‌ها را دقیق بنویسید.

**🟡 متوسط**
با **یک نفر از اطرافیانتان** (خانواده، دوست، همسایه) که شغلش ربطی به برنامه‌نویسی ندارد صحبت کنید. از او بپرسید: «آیا کار تکراری و خسته‌کننده‌ای روی کامپیوتر در محل کارت داری؟» بنویسید:
۱. عنوان شغلی آن فرد (نیازی به نام واقعی نیست).
۲. کار تکراری‌ای که توصیف کرد.
۳. ۲ تا ۳ جمله درباره‌ی اینکه پایتون چطور می‌تواند آن کار را خودکار کند.

**🔴 سخت**
به گیت‌هاب بروید و **یک پروژه‌ی متن‌باز پایتونی پیدا کنید که در ۶ ماه گذشته آپدیت شده** و **حداقل ۵۰۰ ستاره** دارد و در این درس به آن اشاره نشده. بنویسید:
۱. نام پروژه و لینک آن.
۲. تعداد ستاره‌ی فعلی و تاریخی که آن را چک کردید.
۳. سه جمله، با کلمات خودتان، درباره‌ی اینکه این پروژه چه‌کاری انجام می‌دهد.
۴. یک نکته از کد یا مستندات پروژه که خودتان متوجه نشدید.
